# 自主测试与数据同步约定

供 AI Agent 与人工回归时遵循。

## 禁止操作

- **禁止在 Printify 上生成订单**。其余操作（查看、同步、映射、本系统内订单/商品/SCM 操作）可自主测试。

## 错误发现

- 画面**左下角 N 图标**：有页面错误时会变红，点击可查看 issue。测试时注意该图标，发现变红即排查并修复。

## 自主修复流程

- 自主测试 → 发现错误（含 N 变红、控制台/接口报错）→ **自行改代码** → 再继续测试，循环直到通过。

## 数据访问

- **本地数据库**：用 MCP `postgres-supplynexus-local` 的只读 SQL 查询。
- **外部系统**：通过本系统 API 访问 Shopify / Printify 的商品与订单数据。

## 目标

- 外部系统数据**及时同步到本系统**，本系统可**随时监控**外部系统情况。
- 现阶段：**保证本系统与外部系统数据一致**即可。
